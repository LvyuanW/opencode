# 复刻方案规则

目标：把“参考剧本机制”迁移成“新剧本策略”。

必须输出三类内容：

## 1. 保留项

例如：

- 节奏快
- 每集结尾有钩子
- 主角持续反压制
- 爽点密度高

## 2. 替换项

例如：

- 角色身份
- 事件外壳
- 场景
- 冲突触发方式
- 台词表达

## 3. 规避项

例如：

- 连续相同桥段
- 过近的经典台词
- 高识别角色组合
- 可直接对应的表层设定

## 输出模板

```md
## 复刻目标

...

## 保留项

...

## 替换项

...

## 规避项

...

## 新剧设定

...

## 结构迁移原则

...
```
