# 风格拆解规则

目标：提炼参考剧本真正可复用的“机制”。

至少分析以下 6 项：

## 1. 题材类型

如：豪门、逆袭、婚恋、复仇、职场、亲情、马甲、甜宠

## 2. 主角爽点机制

主角如何被压制，又如何反击、翻盘、打脸

## 3. 反派压制机制

反派靠什么压制主角：身份、金钱、舆论、误会、家庭关系

## 4. 单集节奏

- 开头是否直接冲突
- 中段是否反转
- 结尾是否留钩子

## 5. 角色功能关系

谁负责压制，谁负责助攻，谁负责见证，谁负责误会

## 6. 台词风格

- 直白 / 强刺激
- 情绪强 / 克制
- 偏短句 / 偏对冲
