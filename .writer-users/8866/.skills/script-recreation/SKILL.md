# 剧本复刻技能

## 作用

本技能用于把“参考剧本”转化为“新剧本”。

它不追求直接照抄，而是优先复刻以下层级：

1. 节奏
2. 爽点机制
3. 角色功能关系
4. 单集冲突推进方式
5. 结尾钩子设计

它优先替换以下层级：

1. 角色身份外壳
2. 场景外壳
3. 事件表层
4. 台词表达
5. 高识别度桥段细节

---

## 工作流程

```text
/开始 → /导入参考 → /风格拆解 → /复刻方案 → /角色映射 → /目录复刻 → /分集 + 集数 → /自检

```

### 流程说明

1. **开始**：欢迎用户，确认复刻目标、参考材料范围与相似度要求
2. **导入参考**：整理用户提供的参考剧本/目录/角色设定/片段，保存为 `参考材料整理.md`
3. **风格拆解**：分析题材机制、节奏、爽点、钩子、角色功能与桥段模式，保存为 `风格拆解报告.md`
4. **复刻方案**：生成“保留项 / 替换项 / 规避项 / 新壳设定 / 风险边界”的完整方案，保存为 `复刻方案.md`
5. **角色映射**：生成原角色到新角色的映射表、关系图与功能迁移说明，保存为 `角色映射档案.md`
6. **目录复刻**：按“叙事功能等价”的原则生成分集目录，保存为 `复刻分集目录.md`
7. **分集**：按专业剧本格式撰写指定集数的复刻版剧本，每集≥800字，保存为 `第N集_标题.md`
8. **自检**：对已生成内容进行复刻质量与相似度风险双重检查，保存为 `复刻质量自检.md`
9. **导出**：所有文件已保存在当前项目目录，可继续编辑、扩写或转换格式

## 任务确认流程

**前置检查**：如果当前目录已有 `参考材料整理.md` 或 `复刻方案.md`，询问用户是继续现有复刻项目还是开始新项目。

### 第一步：确认参考材料类型

先确认用户当前提供的是哪一种材料：

- **完整剧本**
- **分集目录**
- **单集样本**
- **剧情梗概**
- **角色设定**
- **混合材料**

若材料不完整，必须明确指出“当前可分析范围”和“当前无法可靠复刻的部分”。

### 第二步：确认复刻目标

进一步确认用户希望复刻的核心对象：

- **结构复刻**：保留整体叙事骨架与集数推进方式
- **节奏复刻**：保留单集冲突密度、反转频率、钩子节奏
- **爽点复刻**：保留主角压制—反击—碾压的情绪机制
- **角色功能复刻**：保留人物关系结构与功能分工
- **文风复刻**：保留台词质感、表达习惯、氛围语气
- **综合复刻**：以上多项组合

### 第三步：确认边界与风险控制

必须确认以下内容：

- **相似度目标**：低 / 中 / 高
- **替换强度**：轻改 / 中改 / 重构
- **是否允许保留经典桥段功能**：是 / 否
- **是否需要主动规避高度可识别桥段**：是 / 否
- **是否需要本土化迁移**：中式 / 海外 / 指定地区
- **输出语言**：中文 / 英文
- **输出规模**：单集试写 / 10集以内 / 30-40集 / 50-70集
- **特殊要求**：用户自定义说明

### 第四步：确认启动

汇总用户选择后，提示进入 `/导入参考`。

## 参考材料导入

在执行 `/导入参考` 时，必须对用户提供的材料进行标准化整理，并明确：

**1. 材料来源与类型**

- 用户直接粘贴
- 用户摘要说明
- 用户分段提供
- 用户仅提供部分角色 / 目录 / 单集

**2. 材料覆盖范围**

- 已具备：哪些信息
- 缺失：哪些关键要素
- 可推断：哪些结构与功能
- 不可推断：哪些内容必须等待补充

**3. 参考对象拆分**

- 角色信息
- 关系信息
- 世界观设定
- 分集结构
- 核心爽点
- 常见桥段
- 单集结尾钩子模式
- 台词风格特征

**文件生成**：整理完成后，保存为 `参考材料整理.md`。

完成后引导输入 `/风格拆解`。

## 风格拆解

基于参考材料，生成完整的风格拆解报告，必须至少包含以下模块：

**1. 题材机制**

- 核心题材标签
- 市场归类
- 爽感来源
- 用户预期满足点

**2. 主角机制**

- 主角初始处境
- 压制来源
- 反击路径
- 身份反转 / 能力反转 / 情感反转方式

**3. 反派机制**

- 反派类型
- 压制方式
- 每轮升级方法
- 被打脸节奏

**4. 单集节奏**

- 开场信息密度
- 冲突出现位置
- 反转密度
- 爽点出现频率
- 结尾钩子类型

**5. 桥段模式**

- 常用误会桥段
- 身份揭露桥段
- 家庭/职场/情感冲突桥段
- 围观打脸桥段
- 升级与复仇桥段

**6. 台词与表达风格**

- 是否直白
- 是否高密度刺激表达
- 是否强情绪化
- 是否使用高压挑衅、羞辱、反杀等语气

**7. 角色功能系统**

- 主角
- 对手角色
- 助攻角色
- 证据角色
- 围观角色
- 感情推动角色

**8. 结构规律**

- 前期建置方式
- 中段升级方式
- 付费前爆点设计
- 后期连续高潮机制
- 收束方式

拆解方法详见 [style-extraction.md](references/style-extraction.md)。

**文件生成**：完成后保存为 `风格拆解报告.md`。

完成后引导输入 `/复刻方案`。

## 复刻方案生成

基于风格拆解报告，输出完整的复刻方案。必须包含：

**1. 复刻目标概述**

- 本次复刻要保留什么
- 本次复刻要替换什么
- 本次复刻要规避什么

**2. 新剧基础设定**

- 新剧名（3个备选）
- 新题材外壳
- 新世界观
- 新背景设定
- 新主要矛盾

**3. 保留项**

- 节奏机制
- 爽点密度
- 角色功能关系
- 关键叙事推进逻辑
- 付费卡点设计原则

**4. 替换项**

- 角色身份
- 场景外壳
- 事件表层
- 冲突触发形式
- 关键道具与信息揭露方式

**5. 规避项**

- 直接复写的桥段
- 连续相同的剧情节点
- 高度近似的台词表达
- 高识别度设定
- 可直接对应的角色外壳

**6. 结构映射策略**

- 原剧前中后段如何迁移
- 付费前后如何做差异化处理
- 哪些桥段保留功能但改变表现方式

**7. 风险控制原则**

- 允许相似的层级
- 必须重写的层级
- 可用“功能等价替换”的层级

详细策略见 [adaptation-strategy.md](references/adaptation-strategy.md)。

**文件生成**：方案确认后保存为 `复刻方案.md`。

完成后引导输入 `/角色映射`。

## 角色映射

**前置读取**：生成角色映射前，必须读取：

1. `参考材料整理.md`
2. `风格拆解报告.md`
3. `复刻方案.md`

角色映射必须包含：

**1. 原角色 → 新角色映射表**

- 原角色名
- 原角色功能
- 新角色名
- 新角色身份壳
- 保留的性格核心
- 替换后的社会关系定位

**2. 原关系 → 新关系映射表**

- 情感关系
- 利益关系
- 对立关系
- 权力关系
- 误会链路
- 依赖链路

**3. 角色弧线迁移**

- 原角色成长或堕落路径
- 新角色如何承担同类功能
- 哪些节点要保留
- 哪些节点必须改写

**4. Mermaid 关系图**
使用 Mermaid 清晰展示新角色之间的关系网络。

具体规则见 [character-mirroring.md](references/character-mirroring.md)。

**文件生成**：完成后保存为 `角色映射档案.md`。

完成后引导输入 `/目录复刻`。

## 目录复刻

**前置读取**：生成目录前，必须先读取：

1. `复刻方案.md`
2. `角色映射档案.md`

根据复刻方案，按以下规则生成分集目录：

- 每集2-3分钟时长
- 默认30-70集，可按用户要求缩放
- 每集标注：集数 + 标题 + 本集核心冲突 + 本集爽点 + 本集钩子
- 标注付费卡点集（用 💰 标记）
- 标注重大转折集（用 🔥 标记）
- 标注关键身份揭露/关系翻转/证据反转集
- 必须说明本集承担的**叙事功能**
- 采用“功能等价复刻”，而非表层剧情照搬

目录如过长可分次输出，每次输出后提醒用户输入“继续”查看剩余目录。

**重要：必须输出完整目录后才能进入分集撰写。** 若用户未确认完整目录就要求写分集，应提醒用户先确认全剧节奏与关键转折是否成立。

详见 [structure-mapping.md](references/structure-mapping.md)。

**文件生成**：目录确认后保存为 `复刻分集目录.md`。

完成后引导输入 `/分集 + 集数`。

## 剧本格式

**前置读取**：撰写分集前，必须先读取：

1. `复刻方案.md`
2. `角色映射档案.md`
3. `复刻分集目录.md`
4. 最近2-3集已完成剧本（如存在）

撰写剧本时严格遵循专业格式，详见 [script-format.md](references/script-format.md)。

根据用户选择的输出语言，自动切换格式体系：

**中文剧本格式**：

- 场景头：场次编号 + 内/外景 + 具体地点 + 日/夜
- 出场人物列表
- △ 动作/场景描写（含景别提示）
- 角色名 + (语气/动作) + 台词

**英文剧本格式**：

- 场景头：SCENE + INT./EXT. + LOCATION + DAY/NIGHT
- Cast 列表
- △ 动作/场景描写（含景别提示）
- CHARACTER NAME + (parenthetical) + dialogue

共同要求：

- 每集≥800字
- 3-5个场次
- 每集必须包含明确冲突推进
- 每集结尾必须留有悬念、误导、爆点或反转之一
- 必须优先保持“功能与节奏相似”，而非语言表层相似

**复刻写作额外要求**：

- 不直接复用参考剧本的连续桥段表达
- 不直接照搬高度可识别台词
- 同一叙事功能可通过不同事件外壳来完成
- 保留情绪起伏和压制-反击机制
- 优先做“桥段换壳”而不是“原桥段重述”

详见 [scene-recreation.md](references/scene-recreation.md)。

**文件生成**：每集完成后，保存为 `第N集_标题.md`。

## 自检机制

**前置读取**：执行 `/自检` 时，必须读取：

1. `复刻方案.md`
2. `角色映射档案.md`
3. `复刻分集目录.md`
4. 指定检查集数的剧本
5. 如有必要，读取 `风格拆解报告.md`

自检必须分为两部分：

### A. 复刻质量检查

- 是否保留参考剧本的核心节奏
- 是否保留原有爽点分布机制
- 是否保留角色功能与对抗逻辑
- 是否保留关键情绪爆发节点
- 是否具备连续追看驱动力

### B. 相似度风险检查

- 是否存在可直接对应的连续桥段
- 是否存在台词近似
- 是否存在高识别度角色设定复用
- 是否存在同构但未做足替换的关键情节
- 是否需要降重、改壳或重排

输出时必须给出：

- 问题清单
- 风险等级
- 修改建议
- 是否建议重写本集/某场/某段

详细标准见 [similarity-checklist.md](references/similarity-checklist.md)。

**文件生成**：保存为 `复刻质量自检.md`。

## 总体规则

- 本技能的目标是“机制复刻”和“功能迁移”，不是照抄
- 优先保留：节奏、爽点、叙事推进逻辑、角色功能关系
- 优先替换：角色身份、事件表层、台词表达、场景外壳、触发因果
- 节奏优先级高于文采，钩子优先级高于细腻铺陈
- 若用户提供材料不足，必须明确指出推断边界，不可伪造“参考剧本原貌”
- 每个阶段完成后，主动告知用户下一步操作指令
- 合规意识贯穿始终，参考 [compliance-checklist.md](references/compliance-checklist.md)

## 文档管理

### 文件生成规则

每个阶段完成后，必须生成对应 `.md` 文件并保存在用户当前工作目录：

| 阶段     | 生成文件          | 内容说明                                         |
| -------- | ----------------- | ------------------------------------------------ |
| 参考导入 | `参考材料整理.md` | 整理参考剧本、目录、片段、角色设定及可分析范围   |
| 风格拆解 | `风格拆解报告.md` | 题材机制、爽点系统、节奏、桥段模式、角色功能分析 |
| 复刻方案 | `复刻方案.md`     | 保留项、替换项、规避项、新壳设定、风险边界       |
| 角色映射 | `角色映射档案.md` | 角色映射表、关系图、功能迁移、角色弧线           |
| 目录复刻 | `复刻分集目录.md` | 分集目录、叙事功能、爽点、钩子、付费卡点         |
| 分集撰写 | `第N集_标题.md`   | 单集完整剧本                                     |
| 质量自检 | `复刻质量自检.md` | 复刻质量评估与相似度风险报告                     |

### 文件命名规范

- `参考材料整理.md`
- `风格拆解报告.md`
- `复刻方案.md`
- `角色映射档案.md`
- `复刻分集目录.md`
- `第N集_标题.md`
- `复刻质量自检.md`

### 文件读取策略

在进入新的阶段前，必须先读取已生成的相关文件，确保一致性：

- **风格拆解前**：读取 `参考材料整理.md`
- **复刻方案前**：读取 `参考材料整理.md`、`风格拆解报告.md`
- **角色映射前**：读取 `参考材料整理.md`、`风格拆解报告.md`、`复刻方案.md`
- **目录复刻前**：读取 `复刻方案.md`、`角色映射档案.md`
- **分集撰写前**：读取 `复刻方案.md`、`角色映射档案.md`、`复刻分集目录.md`、最近2-3集剧本
- **质量自检前**：读取 `复刻方案.md`、`角色映射档案.md`、`复刻分集目录.md`、目标剧本
