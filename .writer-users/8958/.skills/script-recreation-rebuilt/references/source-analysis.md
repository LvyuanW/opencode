# 参考材料整理规则

## 目标

把用户给的参考剧本材料，整理成**后续所有阶段都能直接调用的输入底稿**。

这一阶段不负责创作，只负责回答四个问题：

1. 用户到底给了什么
2. 这些材料已经能支持分析到什么程度
3. 缺了什么
4. 下一步最适合做什么

---

## 一、材料类型识别

先判断用户给的是哪一种，或哪几种混合：

| 类型     | 说明                   | 可支持的后续工作                     |
| -------- | ---------------------- | ------------------------------------ |
| 完整剧本 | 含场次、台词、剧情推进 | 可做完整风格拆解、角色映射、目录迁移 |
| 分集目录 | 只有每集梗概或标题     | 适合做结构映射与节奏判断             |
| 单集片段 | 只有某几集或某些场景   | 适合拆台词风格、场景机制、钩子方式   |
| 剧情梗概 | 长摘要或故事介绍       | 适合先做方案，不适合直接高精度复刻   |
| 角色设定 | 角色档案或人物简介     | 适合做角色功能分析                   |
| 混合材料 | 多种材料拼合           | 先统一整理，再判断分析边界           |

---

## 二、已知信息梳理

至少整理以下项目：

### 1. 题材

例如：

- 豪门
- 婚恋
- 逆袭
- 复仇
- 甜宠
- 职场
- 悬疑
- 战神/神豪/马甲

### 2. 主角信息

- 主角是谁
- 主角公开身份
- 主角隐藏身份或核心优势
- 主角处于什么困境

### 3. 主要冲突

- 主角被谁压制
- 压制来自什么：身份、金钱、舆论、误会、家庭关系、职场结构
- 主要反击是如何展开的

### 4. 角色关系

- 主角与反派关系
- 主角与爱人/盟友/家人关系
- 有没有误会制造者、证据提供者、围观见证者

### 5. 节奏材料

- 是否有完整目录
- 是否能看出单集节奏
- 是否能识别结尾钩子模式

### 6. 台词材料

- 是否有完整台词
- 台词偏刺激、偏克制、偏短句还是偏对冲

---

## 三、缺失信息判断

必须明确指出哪些信息缺失会影响后续阶段。

常见缺口：

| 缺失项         | 会影响什么                 |
| -------------- | -------------------------- |
| 缺完整目录     | 结构迁移精度下降           |
| 缺场景与台词   | 场景复刻与语言迁移精度下降 |
| 缺角色关系     | 角色映射容易失真           |
| 缺关键转折信息 | 后续目录样稿容易节奏偏差   |
| 缺目标集数     | 无法判断目录规模           |
| 缺相似度要求   | 方案难以确定保留/替换强度  |

---

## 四、边界表达

必须把结论分成两类：

### 当前可分析范围

例如：

- 可以拆题材与爽点机制
- 可以做角色功能映射
- 可以先做前 5 集目录样稿

### 当前不可确认范围

例如：

- 暂时无法高精度判断后半程高潮结构
- 暂时无法复刻原作台词风格
- 暂时不适合直接整季写作

---

## 五、推荐下一步

整理完成后，给出清晰建议：

- 材料足够：推荐进入 `/风格拆解`
- 材料只够做大框架：推荐先做 `/复刻方案`
- 材料明显不足：建议补以下材料后再继续
