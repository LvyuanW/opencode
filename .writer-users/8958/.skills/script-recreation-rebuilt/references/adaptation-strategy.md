# 复刻方案规则

## 目标

把“参考剧本的有效机制”迁移成“新剧的执行策略”。

这一阶段不是写正文，而是确定：

1. 什么保留
2. 什么替换
3. 什么规避
4. 新剧的外壳和边界怎么定

---

## 一、先选复刻策略

常见策略有四种：

| 策略       | 适用情况                       | 特点                         |
| ---------- | ------------------------------ | ---------------------------- |
| 结构迁移型 | 有完整目录或完整剧本           | 保留整体推进骨架，外壳大换   |
| 节奏迁移型 | 只拿到片段或单集样本           | 保留单集刺激方式，剧情层重写 |
| 角色功能型 | 角色关系很强、戏剧张力主要靠人 | 保功能网络，改设定壳         |
| 安全降重型 | 用户特别在意风险               | 只保机制，不保明显表层       |

若用户没明确指定，默认采用：
**节奏迁移 + 角色功能 + 中等安全降重**

---

## 二、必须输出的三大块

## 1. 保留项

写清哪些机制必须保留。

常见可保留项：

- 节奏快
- 单集冲突密
- 主角持续反压制
- 钩子强
- 围观者见证打脸
- 身份层层揭露
- 情绪强、台词短

注意：保留的是“机制”，不是“桥段皮相”。

---

## 2. 替换项

写清哪些表层必须换掉。

常见替换项：

- 角色身份
- 场景外壳
- 冲突触发方式
- 关系表层
- 关键事件的具体执行壳
- 台词风格表达

替换时可按以下顺序动手：

1. 先换身份壳
2. 再换场景壳
3. 再换冲突载体
4. 最后换台词与桥段细节

---

## 3. 规避项

写清哪些地方不能太近。

高风险项常见包括：

- 连续相同桥段
- 原作经典台词
- 高识别度人物组合
- 关键转折点几乎一一对应
- 高识别道具、场景、场面调度

---

## 三、新剧设定怎么定

新剧设定至少回答：

- 新题材壳是什么
- 新主角是谁
- 新反派如何压制
- 新剧的主要舞台是什么
- 新剧最大的差异化卖点是什么

建议用一句话完成新剧定位，例如：

- “保留身份反转与高密度打脸机制，把豪门婚恋迁移到跨境直播电商职场线。”
- “保留误会—反击—真相揭露的节奏，把家庭伦理壳替换为艺人经纪人与娱乐舆论战。”

---

## 四、结构迁移原则

迁移目录或分集时，建议遵守：

1. 功能等价，不做剧情翻译
2. 关键节点可以对应，但表层要变
3. 高识别桥段不要连续复用
4. 前 5 集优先验证节奏，不急着整季铺满
5. 样章不过关前，不建议批量分集

---

## 五、相似度目标建议

| 目标     | 建议                                                   |
| -------- | ------------------------------------------------------ |
| 低相似度 | 大换身份壳、关系壳和关键事件壳，只保节奏和功能         |
| 中相似度 | 保留主要机制与部分目录结构，但重写桥段外壳             |
| 高相似度 | 仅用于内部研究或明确低风险场景；公开创作不建议默认采用 |
