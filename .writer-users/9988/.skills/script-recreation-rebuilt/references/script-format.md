# 剧本格式规则

## 目标

使用**简化但专业可拍**的中文短剧剧本格式。

保证：

- 结构清楚
- 场次明确
- 台词与动作分离
- 适合继续交给导演、分镜或二次加工

---

## 基础格式

```md
# 第1集 标题

## 场1

【内景 / 地点 / 日】

出场人物：A、B

△ 动作或环境描述

A（语气/动作）：
台词

B（语气/动作）：
台词

## 场2

【外景 / 地点 / 夜】

出场人物：A、C

△ 动作或环境描述
...
```

---

## 书写要求

### 场景头

必须写清：

- 内景 / 外景
- 地点
- 日 / 夜

### 出场人物

只列本场实际出现的人物。

### 动作描述

- 用 `△` 开头
- 简洁
- 主要写画面变化、动作和情绪状态
- 不要写成长段文学描写

### 台词

- 一人一段
- 口语化
- 单句尽量简短
- 让台词承担“推进剧情 / 展示人物 / 制造冲突”中的至少一个功能

---

## 建议附加项

在关键场景可增加：

- 特写提示
- 声音提示
- 道具特写
- 情绪节奏提示

但不要写得像分镜头脚本那样过细，避免锁死后续执行空间。

---

## 结尾

每集结尾建议单列：

```md
## 结尾钩子

- ...
```

便于后续做目录校对与上下集衔接。
