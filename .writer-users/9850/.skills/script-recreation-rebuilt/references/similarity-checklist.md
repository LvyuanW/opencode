# 相似度自检规则

## 目标

在输出目录、样章或批量分集后，做两类检查：

1. 复刻质量是否成立
2. 相似度风险是否过高

自检不是一句“有点像”，而是要指出：

- 像在哪
- 风险等级多高
- 怎么改

---

## 一、复刻质量检查

至少检查以下项目：

- 节奏是否成立
- 爽点是否成立
- 主角反击是否成立
- 钩子是否有效
- 角色功能是否清晰
- 本集/本段是否完成了应承担的叙事任务

可从“优点 / 问题”两部分来写。

---

## 二、相似度风险检查

重点检查四类问题：

### 1. 桥段风险

- 是否有连续桥段过近
- 是否有高识别桥段直接平移

### 2. 台词风险

- 是否有明显近似表达
- 是否有经典句式被保留得太多

### 3. 角色风险

- 是否有角色身份壳过近
- 是否有人物关系一一映射过强

### 4. 结构风险

- 是否关键转折点顺序过近
- 是否目录功能与节点几乎完全同构

---

## 三、风险等级建议

| 等级 | 说明                     | 建议                     |
| ---- | ------------------------ | ------------------------ |
| 低   | 机制相似但表层差异充分   | 可继续推进               |
| 中   | 局部桥段/角色/结构仍偏近 | 建议先修改再扩写         |
| 高   | 多处高识别点对应明显     | 建议重做方案或重写关键集 |

---

## 四、常用修改手段

发现风险后，可优先这样改：

1. 降低表层相似
2. 替换桥段外壳
3. 重写高风险台词
4. 改写高识别设定
5. 调整关键转折顺序
6. 拆分或合并角色功能
