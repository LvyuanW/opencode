# 01\_参考材料整理

## 材料类型

- **类型**：完整剧本（含场次、台词、剧情推进）
- **已完成集数**：第1-5集
- **格式**：分场结构，每集3场，含场景描述、人物出场、台词、结尾钩子
- **支持后续工作**：可做完整风格拆解、角色功能映射、目录迁移、场景机制分析

---

## 已知信息

### 题材

都市 / 误会 / 先婚后爱 / 马甲 / 打脸 / 轻喜短剧

核心标签可归纳为：

- 豪门情感线（顾氏集团继承人）
- 身份错位（真未婚妻被误认为临时女友）
- 马甲揭露（女主真实身份逐步暴露）
- 轻喜剧调性（男主傲娇 + 女主冷脸 = 反差笑点）

### 主角

**林晚（女主）**

- 公开身份：机场偶遇的普通女人 / 临时女友
- 隐藏身份：顾家长辈当年定下的正式未婚妻
- 核心优势：了解男主生活细节、熟知金融圈信息、手里有婚约信物（旧玉镯）
- 困境：低调回国确认婚约，却被男主强行拉入"假女友"局

**顾承泽（男主）**

- 公开身份：顾氏集团继承人
- 核心困境：被奶奶催婚，临时找人演女友挡家宴
- 性格特质：外冷内拽、嘴硬心软、掌控欲强
- 成长方向：从"掌控全局"到"开始追妻"

### 主要冲突

**第一层（第1-3集）：身份错位冲突**

- 女主被男主强行拉入假女友角色
- 女配苏蔓以为女主要是"捞女"，当众打压
- 男主完全不知道女主真实身份

**第二层（第4集）：信息揭露冲突**

- 婚约真相被老夫人揭破
- 男主震惊，需要重新认识"未婚妻"
- 女主反客为主：婚约是长辈定的，人我还没定

**第三层（第5集）：追妻竞争冲突**

- 新角色沈宴出场（青梅竹马/备选未婚夫）
- 男主从被动接受婚约 → 主动追妻
- 女主掌握主动权，要求男主"排队"

**压制来源：**

- 苏蔓（女配）：身份质疑、舆论打压、公开羞辱
- 男主自身：傲慢、自以为掌控一切、缺乏真心
- 信息差：男主不知女主身份，被蒙在鼓里

**反击方式：**

- 女主低调露馅（说出男主生活细节、写出并购案尾数）
- 以冷对热（面对男主的强势，始终冷静掌控节奏）
- 利用信息优势（知道婚约、知道男主习惯、知道金融数据）

### 角色关系

| 角色     | 与女主关系      | 功能                             |
| -------- | --------------- | -------------------------------- |
| 顾承泽   | 男主/未婚夫     | 情感对象，也是误会制造者         |
| 苏蔓     | 情敌            | 反派/打压者/打脸对象             |
| 顾老夫人 | 男主奶奶/知情人 | 信息提供者/盟友/催婚推动者       |
| 周扬     | 男主助理        | 转场工具/旁观见证者/小笑点提供者 |
| 沈宴     | 青梅竹马        | 竞争者/刺激男主/制造危机感       |

**信息差分布（关键机制）：**

- 顾老夫人：知道最多（认出玉镯、提及沈清禾）
- 林晚：知道自己是未婚妻，但不确定男主态度
- 顾承泽：只知道婚约存在，不知道女主早知道
- 苏蔓：最晚知道，每次都被打脸
- 周扬：中间层，知道一点但不知道全部

### 节奏材料

- **单集结构**：每集3场，节奏紧凑
- **结尾钩子模式**：每集结尾卡在"信息升级点"或"悬念点"
  - 第1集：顾老夫人认出玉镯（身份钩子）
  - 第2集：苏蔓开始怀疑（反派钩子）
  - 第3集：顾老夫人要揭牌（剧情钩子）
  - 第4集：女主不认这门婚（情感钩子）
  - 第5集：男主开始正式追妻（阶段钩子）
- **叙事弧**：相遇(1) → 试探(2) → 暴露(3) → 揭牌(4) → 反转(5)

### 台词材料

- **风格**：短句为主，对冲感强，有"呛声"质感
- **特征**：
  - 女主台词冷、简、准（"你有病？""有些事，不用调查。"）
  - 男主台词傲但软（"闭嘴。""行，那我排第一个。"）
  - 对话常以"一句话堵死对方"收尾
  - 轻喜感来自"男主嘴硬 → 被打脸 → 不得不服"的循环
- **经典对白模式**：
  - 男主说A → 女主做B（打脸）
  - 女配说C → 女主回D（反杀）
  - 永远是"被低估的人"做出出人意料的回应

## 当前可分析范围

- 可完整拆解题材、爽点机制、压制机制、节奏模式
- 可做核心角色功能映射（5个主要角色均已出场）
- 可分析单集钩子模式与台词风格
- 可先做前5集目录样稿（基于已知剧情弧）
- 剩余5集可基于"中等迁移"原则自主编排

## 当前不可确认范围

- 无法精确复刻后半程高潮结构（原剧未提供第6-10集）
- 复刻版需在第5集之后自行设计新外壳下的剧情走向
- 不影响整体复刻质量——中等迁移本身就是鼓励自主编排的

3. 缺失的后续集数不影响风格拆解，反而给自主编排留出空间
