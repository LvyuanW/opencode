# 03\_复刻方案

## 复刻目标

- 参考原剧《他把我当临时女友，没想到我真是他未婚妻》
- 中等迁移：保留核心爽点机制，做明显外壳差异化
- 目标体量：10集以内
- 风格定位：都市轻喜情感短剧

---

## 复刻策略

**策略组合**：结构迁移 + 角色功能 + 中等安全降重

- 保留整体叙事骨架与节奏机制
- 替换身份外壳、场景壳、冲突载体
- 桥段层面做功能等价改写，不做剧情翻译

**一句话定位**：

> 保留"假身份掩盖真身份"的核心错位机制，将豪门婚恋壳迁移到 **传媒/娱乐圈背景**——他是顶级娱乐公司的冷面CEO，她是他临时抓来当"合约CP"的新人编剧，殊不知她正是爷爷当年指定的未婚妻。

---

## 保留项

### 机制保留（必须）

1. **身份错位机制**：女主的真实身份比所有人以为的都高，但始终保持低调，逐层揭露
2. **信息差驱动**：所有冲突建立在"有人知道、有人不知道"的结构上
3. **逐层打脸节奏**：每集1-2个"低调反杀"时刻，压制升级 → 反杀释放
4. **钩子类型轮换**：每集结尾钩子类型不同（身份/反派/剧情/情感/阶段）
5. **冷脸女主 + 傲娇男主**的反差喜剧底色
6. **轻喜基调**：冲突不虐，打脸不恶毒

### 节奏保留（必须）

- 开场即冲突的单集节奏
- 场1引入冲突、场2释放反击、场3收束+钩子的三场结构
- 爽点（打脸/反杀）落在场2中后段

### 角色功能保留（必须）

- 女主：被低估者，掌握信息优势，逐层反杀
- 男主：从傲慢到追妻，提供情感线张力
- 女配：即时打脸对象，负责制造每集小冲突
- 长辈/知情人：负责揭破真相、推动剧情
- 竞争者：刺激男主、制造追妻危机感
- 围观者：放大打脸效果

## 替换项

### 身份外壳替换

| 原设定                   | 新设定                                             |
| ------------------------ | -------------------------------------------------- |
| 林晚：低调回国的未婚妻   | **苏念**：刚回国的新人编剧，实际是傅家指定的未婚妻 |

| 苏蔓：顾承泽的"绯闻对象" | **姜薇**：公司力捧的当红女演员，傅司衍的"官方CP"   |
| 顾老夫人：男主奶奶       | **傅老爷子**：曜星传媒创始人，当年与苏家定下婚约   |

## 规避项

### 高识别风险点（必须规避）

1. **机场强拉假女友的开篇**：替换为"公司大厅临时绑CP"，避免标志性场景
2. **"并购案尾数"反杀细节**：替换为"内部选角名单"或"项目报价底价"，功能等价但载体不同
3. **"支票羞辱"经典桥段**：替换为"当众贬低+资源打压"，避免高识别桥段
4. **顾氏集团 + 顾老夫人的角色组合**：替换为曜星传媒 + 傅老爷子，拉开差距
5. **"演一个离不开我的女人"标志性台词**：功能等价替换，不直接复用
6. **"婚约是长辈定的，人我还没定"**：功能保留但表达重写

### 中等风险点（建议规避）

1. 同样的"3场结构"不要每次都用完全相同的场景转换模式
2. 女主打脸的方式要多样化，不要只靠"说出对方不知道的信息"
3. 男主从傲到软的转折节点要错开，不要集中在第4集

## 新剧设定

**新剧名称（暂定）**：《他让我当合约女友，没想到我是他真未婚妻》

**题材**：都市 / 娱乐圈 / 轻喜 / 先婚后爱 / 马甲 / 打脸

**世界观**：

- 背景为国内顶级传媒公司"曜星传媒"
- 娱乐圈生态：资源博弈、舆论操控、CP营销、选角暗战
- 既有商业角力的爽感，又有娱乐圈花边的轻喜剧感

**主角设定**：

**苏念（女主）**

- 公开身份：刚回国的新人编剧，业内无名
- 隐藏身份：傅家与苏家二十年前定下的未婚妻，手里有婚约信物
- 核心优势：了解娱乐圈底层运作、有海外编剧经验、手握爆款项目信息
- 性格：低调冷静，不爱解释，以事实说话

**傅司衍（男主）**

- 公开身份：曜星传媒CEO，冷面商业天才
- 核心困境：公司需要CP营销带热度，被爷爷催婚
- 性格：外冷内热，掌控欲强，嘴硬心软
- 转变：从"把她当工具"到"想认真追她"

**差异化卖点**：

1. 娱乐圈背景天然自带"打脸围观效应"——媒体、粉丝、同行都是放大器
2. "合约CP vs 真未婚妻"的双层身份错位比"假女友 vs 真未婚妻"更具戏剧张力
3. 资源博弈（项目、角色、档期）比单纯的金钱博弈更有行业质感

---

## 结构迁移原则

1. **功能等价，不做剧情翻译**：原剧第1集"机场抓人" → 新剧"公司大厅绑CP"，功能相同（偶然相遇+被迫绑定），但场景完全不同
2. **关键节点可以对应，但表层要变**：认信物、揭真相、拒婚约、出现竞争者等功能节点保留，但载体和方式全部重写
3. **高识别桥段不连续复用**：原剧第3集"支票反杀"和第5集"沈宴出场"不会以同样的外壳连续出现
4. **前5集优先验证节奏**：先出前5集目录样稿，样章过关后再扩到完整10集
5. **样章不过关不批量分集**：先写第1集样章，验证节奏和风格后再推进

---

## 一句话概述

> **保留原剧"假身份掩盖真身份"的核心错位机制与逐层打脸节奏，将豪门婚恋壳迁移到传媒娱乐圈——他是曜星传媒的冷面CEO，她是他临时抓来绑CP的无名编剧，所有人都不知道：她才是爷爷当年指定的真正未婚妻。**

## 风险评估

| 风险点                   | 等级     | 建议                                             |
| ------------------------ | -------- | ------------------------------------------------ |
| 娱乐圈背景已有大量同类剧 | 中       | 用"编剧+项目资源"替代常见"演员"设定，拉开差异化  |
| 女主打脸方式容易套路化   | 中       | 在分集写作时注意多样化反杀手段                   |
| "合约CP"设定也已有先例   | 低       | 核心卖点不是合约CP本身，而是"真未婚妻"的双重身份 |
| 总体方案风险             | **中低** | 可继续推进角色映射阶段                           |

## 下一步建议

推荐进入 **角色映射** 阶段，将核心角色功能从原剧迁移到新设定中。
