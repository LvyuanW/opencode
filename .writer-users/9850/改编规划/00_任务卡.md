## 参考剧核心机制提炼（初步）

1. **身份错位机制**：女主是真未婚妻，男主不知情还当她是临时演员，制造持续戏剧反讽
2. **信息差分布**：老夫人知情最多 → 女主知道自己是未婚妻 → 男主完全不知 → 女配（苏蔓）最晚知道
3. **打脸节奏**：每集安排1-2个女主"低调露馅"时刻，逐步暴露真实身份/能力
4. **钩子模式**：每集结尾卡在信息升级点（认镯子→起疑→对质→拒婚→情敌出场）
5. **轻喜基调**：男主傲娇 + 女主冷脸 = 反差喜剧

## 推荐工作路径

1. **参考整理** → 整理原剧可分析范围
2. **风格拆解** → 拆题材、爽点、压制机制、节奏、角色功能
3. **复刻方案** → 确定保留项、替换项、规避项与新剧设定
4. **角色映射** → 核心角色功能迁移
5. **目录** → 生成前5集样稿目录（或用户确认后扩为完整目录）
6. **分集** → 先写样章，再推进后续集数
7. **自检** → 检查复刻质量与相似度风险
8. **导出** → 生成总索引
