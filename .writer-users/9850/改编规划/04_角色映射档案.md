## 核心角色详述

### 苏念（女主）

**原角色**：林晚

**原角色功能**：

- 被男主误认为临时女友
- 手握婚约信物，真实身份是未婚妻
- 冷静克制，以事实打脸
- 逐层暴露身份优势

**新身份外壳**：

- 刚从海外回国的新人编剧，业内没有背景
- 表面上是傅司衍临时抓来"绑CP"的工具人
- 实际是傅家与苏家二十年前定下的未婚妻，手里有婚约信物（一块旧怀表 + 一封当年的手写协议）

**保留核心作用**：

- 被低估者：所有人都以为她没背景、没实力
- 信息优势者：她知道婚约、了解傅司衍的偏好、掌握行业内幕信息
- 冷面反杀：从不解释，只用事实说话

**新剧冲突点**：

- 她来曜星传媒是为了凭实力证明自己，不是为了靠婚约上位
- 被迫当"合约CP"打乱了她的独立计划
- 姜薇的打压让她不得不暴露一部分真实能力

**爽点/反转功能**：

- 每集一次"低调露馅"：她说出不该知道的信息，做出新人做不到的事
- 核心反转：她不是"想攀高枝"，而是"被拉进来"后发现自己才是那个真正该坐在那里的人

---

### 傅司衍（男主）

**原角色**：顾承泽

**原角色功能**：

- 为躲催婚，强行拉人演女友
- 外冷内拽，掌控欲强
- 从傲慢到被迫接受再到主动追妻

**新身份外壳**：

- 曜星传媒CEO，商科出身的商业天才
- 公司需要热度，爷爷催婚，双重压力下做出"绑CP"的决定
- 选中苏念是因为"看起来省事"——低调、不张扬、不会反咬

**保留核心作用**：

- 傲娇：嘴上说不在乎，行动上越来越在意
- 掌控欲：习惯主导一切，但被苏念一次次打破预期
- 追妻转变：从"把她当工具"到"想认识真正的她"

**新剧冲突点**：

- 他以为自己选了个最省事的人，结果选了最难搞定的那个
- 他抗拒婚约是因为"被安排"，但开始被苏念本人吸引
- 面对陆时安的出现，第一次感受到不是所有人都绕着他转

**爽点/反转功能**：

- 他的"傲"被苏念一次次冷处理
- 每次试图掌控局势，都被苏念用更冷静的方式化解
- 从"我选的她"变成"原来她才是那个被选中的人"的反转

---

### 姜薇（女配）

**原角色**：苏蔓

**原角色功能**：

- 男主身边"最接近顾太太位置"的绯闻对象
- 身份压制、舆论打压、公开羞辱女主
- 每集被打脸的对象

**新身份外壳**：

- 曜星传媒当家花旦，人气最高的一线女演员
- 公司长期用她和傅司衍的"暧昧互动"做营销素材
- 她真心以为自己是最接近傅太太的人

**保留核心作用**：

- 即时打脸对象：每集制造一次对苏念的压制
- 压制方式：身份（"你一个新人"）、资源（"我能决定角色给谁"）、舆论（"她就是想蹭热度"）
- 被打脸后不服气，下次更狠，形成循环

**新剧冲突点**：

- 她不是纯粹的坏人，而是"长期被资源宠坏的人"
- 她的打压来自恐惧——害怕失去"唯一"的位置
- 苏念的出现打破了她的安全感

**爽点/反转功能**：

- 她每次打压苏念，反而帮苏念暴露了更多实力
- 她越嚣张，被打脸时观众越爽
- 后期可能有一条从对手到释怀的弧线（非必须，视集数而定）

---

### 傅老爷子（关键助攻）

**原角色**：顾老夫人

**原角色功能**：

- 知道婚约真相的人
- 一眼认出信物
- 推动真相揭破
- 站在女主一边

**新身份外壳**：

- 曜星传媒创始人，退居幕后但仍有影响力
- 当年与苏家定下婚约的长辈，一直在找苏家后人
- 在公司年会上第一次见到苏念，注意到她手上的旧怀表

**保留核心作用**：

- 知情者：他是唯一知道全部真相的人
- 推动者：在关键时刻推动真相揭破（第4集前后）
- 盟友：始终站在苏念一边，甚至"偏心"她

**新剧冲突点**：

- 他和傅司衍之间有代际冲突——爷爷认为婚约神圣，孙子认为被安排的人生不想接受
- 他私下帮助苏念，但苏念并不想靠关系
- 他的介入方式是"慈祥的强势"，不直接摊牌，而是制造机会让人自己发现

**爽点/反转功能**：

- 他认出怀表的瞬间是全剧关键转折点
- 他站苏念的表态让姜薇的打压瞬间失效
- 他的存在让傅司衍从"主宰者"变成"被安排的人"，制造权力反转的喜剧效果

---

### 贺明（转场工具/旁观者）

**原角色**：周扬

**原角色功能**：

- 推进剧情的工具人
- 旁观见证，放大爽感
- 提供轻喜笑点

**新身份外壳**：

- 傅司衍的经纪人兼助理
- 知道一点内情但不知道全部
- 经常被傅司衍的决定搞糊涂，也经常被苏念的操作震惊

**保留核心作用**：

- 转场功能：每集需要切换场景/推进时，由他出现
- 旁观见证：他代表"普通人视角"，他的震惊放大了苏念的反杀效果
- 轻喜笑点："顾总，她比您还像谈判的" → "傅总，她比您还像老板"

---

### 陆时安（竞争者）

**原角色**：沈宴

**原角色功能**：

- 女主青梅竹马/备选未婚夫
- 出现制造男主危机感
- 推动男主从被动接受婚约到主动追妻

**新身份外壳**：

- 苏念在海外合作过的知名制片人
- 手握多个国际项目资源
- 对苏念有好感，也了解她的才华

**保留核心作用**：

- 竞争者：他的出现让傅司衍意识到苏念不是"没有选择"
- 危机感制造者：他代表了一个"如果傅司衍不珍惜，苏念随时可以走"的选项
- 推动追妻：男主第一次被真正激起胜负欲

**新剧冲突点**：

- 他不是坏人，甚至很优秀，这让傅司衍的压力更真实
- 他手里有项目，能给苏念提供傅司衍给不了的机会
- 他和傅司衍的对峙不是"打脸"，而是"两个同样优秀的人争夺同一个人"

## 关系映射

### 压制关系

```
姜薇 → 苏念（身份+资源+舆论压制）
傅司衍（傲慢） → 苏念（情感+权力压制）
外界舆论 → 苏念（"新人想攀高枝"）
```

### 帮助关系

```
傅老爷子 → 苏念（信息提供 + 站队支持）
贺明 → 苏念（旁观见证，间接放大反杀效果）
```

### 误会关系

```
傅司衍误会苏念是"普通人/想攀高枝"
姜薇误会苏念是"来路不明的新人"
所有人（除傅老爷子）不知道苏念的真实身份
```

### 竞争关系

```
姜薇 ↔ 苏念（争夺"傅司衍身边的位置"）
陆时安 ↔ 傅司衍（争夺苏念本人）
```

### 见证关系

```
贺明：全程旁观，代表普通人的震惊反应
公司员工/媒体：放大每一次打脸的围观效果
```
