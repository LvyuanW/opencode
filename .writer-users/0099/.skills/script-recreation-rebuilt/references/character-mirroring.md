# 角色映射规则

## 目标

不照搬角色表层，而是保留其**叙事功能**。

角色映射的重点不是“换个名字”，而是回答：

- 原角色在原剧里承担什么作用
- 这个作用在新剧里由谁来承担
- 新角色的身份外壳如何换掉
- 保留哪些内核，替换哪些表层

---

## 一、默认先做哪些角色

默认先做核心角色，不急着一次性铺满全员。

推荐先做：

| 类别               | 数量 | 说明                     |
| ------------------ | ---- | ------------------------ |
| 主角               | 1-2  | 观众代入中心             |
| 核心对手           | 1-2  | 压制与对抗的主要来源     |
| 关键助攻/证据角色  | 1-2  | 负责推动反转、揭示真相   |
| 感情推动者（如有） | 1    | 适用于甜宠、婚恋、虐恋线 |

通常 3~5 个核心角色就足够支撑前期目录样稿。

---

## 二、每个角色必须说明的内容

每个角色至少说明：

- 原角色
- 原角色功能
- 新角色
- 新身份外壳
- 仍保留的核心作用

建议再补两项：

- 该角色在新剧中的冲突点
- 该角色承担的爽点/反转功能

---

## 三、常见角色功能

| 功能       | 说明                           |
| ---------- | ------------------------------ |
| 主角       | 被压制并最终反击的人           |
| 对手       | 主要压制来源                   |
| 助攻       | 帮主角推进剧情、制造反差       |
| 证据提供者 | 提供真相、文件、录音、身份线索 |
| 误会制造者 | 导致关系裂痕或信息偏差         |
| 围观见证者 | 放大爽点，形成群体反应         |
| 感情推动者 | 推动情感靠近或误解加深         |

---

## 四、关系迁移

除了单人映射，还要写**关系迁移**。

至少说明：

- 谁压制谁
- 谁帮助谁
- 谁制造误会
- 谁触发反转
- 谁在关键场景中做见证

这样后面的目录和分集才不会散。

---

## 五、角色弧线简写

不用一次写成厚重人物小传，但建议给核心角色写一句弧线概括：

- 主角：隐忍被压制 → 局部反击 → 主导局面
- 反派：嚣张压制 → 节节失手 → 崩盘
- 关键配角：观望/误解 → 倒向主角 → 推动反转

---

## 六、风险提醒

角色映射阶段要特别检查三类风险：

1. 身份壳太像
2. 关系结构几乎一一对应
3. 多个角色都只是“换名不换人”

如果出现以上情况，优先调整：

- 身份体系
- 关系载体
- 角色功能拆分或合并
