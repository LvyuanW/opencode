# 目录复刻规则

## 目标

按“叙事功能等价”的原则生成新目录，而不是复制原剧情表层。

目录阶段要解决的问题是：

1. 每一集承担什么功能
2. 节奏是否能持续追看
3. 爽点、钩子、反转是否分布合理
4. 哪些地方容易与原作过近

---

## 一、目录开发的默认方式

若用户没有明确要求整季，默认先做：

- 前 5 集目录样稿

前 5 集的作用不是把全剧讲完，而是验证：

- 开局是否抓人
- 角色功能是否成立
- 冲突链是否顺
- 钩子是否能带动下一集

只有当前 5 集方向稳定，再考虑扩展 10 集、30 集或整季。

---

## 二、每集必须包含的字段

每集至少包含：

- 集数
- 标题
- 核心冲突
- 爽点
- 结尾钩子
- 本集叙事功能

必要时可补充：

- 本集主要出场角色
- 本集风险提示
- 是否为关键付费卡点/重大转折点

---

## 三、常见叙事功能库

目录设计时可优先从以下功能中选择：

- 建立压制
- 制造误会
- 初次反击
- 升级冲突
- 身份悬念
- 证据反转
- 关系翻转
- 阶段性胜利
- 大反扑前夜
- 高潮收束

同一种功能可以连续出现，但不能一直用同一种桥段外壳。

---

## 四、前 5 集推荐节奏

一个常用的前 5 集节奏示例：

| 集数  | 主要任务                         |
| ----- | -------------------------------- |
| 第1集 | 开局冲突 + 主角困境 + 第一层钩子 |
| 第2集 | 压制升级 + 主角露出一点不同寻常  |
| 第3集 | 第一次小反击 / 小打脸            |
| 第4集 | 误会或更大压力到来               |
| 第5集 | 阶段性爽点 + 更强悬念            |

这不是固定模板，但适合作为短剧开局的安全起点。

---

## 五、完整目录扩展建议

若用户要扩完整目录，可按以下分段：

- 1-5 集：开局引爆
- 6-10 集：冲突升级
- 11-20 集：持续推进与第二层秘密
- 21-30 集：阶段高潮与关系翻转
- 31-40 集：危机加深 / 大反扑
- 41-50 集：高密度反转
- 51-60 集：终局收束

如果是 30-40 集项目，则合并中段与高潮段。

---

## 六、目录风险控制

以下情况容易太像原作：

1. 关键转折顺序几乎完全一致
2. 每一集的冲突载体都能一一对号入座
3. 标题风格和标题信息过近
4. 钩子形式连续重复原剧设计

遇到这些问题，优先改：

- 事件外壳
- 角色参与顺序
- 钩子信息点
- 爽点释放方式

---
