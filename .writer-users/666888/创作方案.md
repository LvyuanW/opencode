# 《凤还巢》创作方案

## 一、基础信息

### 剧名备选

1. **《凤还巢》** —— 寓意穿越女主如凤凰涅槃，最终回归巅峰
2. **《帝王掌心娇》** —— 强调帝王与女主的情感纠葛
3. **《穿越逆袭：冷帝的掌心宝》** —— 直点穿越 + 甜宠 + 逆袭核心

### 推荐剧名

**《凤还巢》**

### 目标受众

女频（18-35岁女性观众为主）

### 语言风格

古风典雅 + 现代智慧碰撞 + 金句频出

---

## 二、时空背景

### 时代设定

架空虚构王朝「大燕王朝」，设定为类似盛唐背景，但不完全对应任何真实朝代，便于创作自由发挥。

### 地点场景

- **皇宫**：太和殿、御花园、坤宁宫、长春宫、冷宫、各嫔妃宫殿
- **京城**：侯府、将军府、醉仙楼、各大世家府邸
- **其他**：边关、行宫、寺庙等

### 社会环境

- 等级森严的后宫制度
- 前朝与后宫的紧密关联（皇帝 vs 太后 vs 各派系）
- 新帝登基不久，皇位不稳，暗流涌动
- 世家贵族把持朝政，与皇权形成博弈

---

## 三、故事核心

### 一句话故事线

现代法医苏晚意外穿越成被打入冷宫的失宠妃嫔，凭借现代智慧与独立人格，在波诡云谲的后宫中步步为营，最终收获冷面帝王最深的宠爱，并助其稳固江山，成为一代贤后。

### 核心冲突

1. **生存危机**：冷宫生存 → 打破冷宫 → 立足后宫
2. **身份对立**：现代灵魂 vs 古代规则（自由平等 vs 三从四德）
3. **情感拉锯**：帝王的防备审视 vs 女主的真诚热烈
4. **权力博弈**：太后一派 vs 皇帝一派，女主夹缝求生
5. **情敌对抗**：白莲花贵妃、虚伪淑妃等轮番陷害

### 主角困境与目标

- **短期目标**：活下来，离开冷宫
- **中期目标**：在后宫站稳脚跟，保护身边的人
- **终极目标**：收获真爱，助帝王成就盛世，自己活成想要的样子

## 四、叙事结构

### 三幕拆解（60集规模）

#### 第一幕：建置（1-12集，20%）

| 集数    | 内容               | 核心任务                               |
| ------- | ------------------ | -------------------------------------- |
| 1-3集   | 穿越落地、冷宫初定 | 建立女主现代灵魂身份、与帝王第一次相遇 |
| 4-6集   | 小试牛刀、初露锋芒 | 女主用现代智慧解决宫廷小危机，获得注意 |
| 7-9集   | 引起注意、危机降临 | 帝王开始关注，引来贵妃嫉妒，第一次陷害 |
| 10-12集 | 危机爆发、绝处逢生 | 女主遭遇重大危机但巧妙化解，付费卡点   |

**第一幕爽点**：冷宫逆袭、智斗下人、初遇帝王被惊艳、第一次打脸贵妃

#### 第二幕：对抗（13-45集，55%）

| 集数    | 内容               | 核心任务                           |
| ------- | ------------------ | ---------------------------------- |
| 13-18集 | 脱离冷宫、晋升常在 | 女主获宠，引来更大风浪             |
| 19-24集 | 宠妃养成、甜蜜互动 | 帝后感情升温，但暗藏隐患           |
| 25-30集 | 太后介入、感情危机 | 太后打压、误会产生、第一次虐心分离 |
| 31-36集 | 真相大白、绝地反击 | 误会解除，女主反击，太后一派受挫   |
| 37-42集 | 再度分离、至暗时刻 | 最大危机，女主被迫离宫或假死       |
| 43-45集 | 帝王觉醒、找回女主 | 帝王追妻，感情升华，准备终极对决   |

**第二幕爽点**：连续打脸反派、帝妃甜蜜互动、误会澄清时的反转、女主展露才华

#### 第三幕：解决（46-60集，25%）

| 集数    | 内容               | 核心任务                               |
| ------- | ------------------ | -------------------------------------- |
| 46-50集 | 终极对决、平定天下 | 联手帝王粉碎太后阴谋、揭露真正幕后黑手 |
| 51-55集 | 帝后联手、天下太平 | 最终决战，坏人伏法                     |
| 56-58集 | 情感升华、大婚盛典 | 帝后大婚，昭告天下                     |
| 59-60集 | 圆满结局、撒糖收尾 | 夫妻携手、共赴白首                     |

**第三幕爽点**：终极打脸、全员跪服、帝后撒糖、圆满结局

## 六、结局设计

### 结局类型

**圆满结局** —— 善恶有报，帝后圆满

### 终极爆发点

- 太后一派彻底覆灭
- 女主真正身份（前世记忆/隐藏身世）揭晓
- 帝王当众宣布废后改立，昭告天下
- 帝后大婚，普天同庆

### 情感升华

- 帝王从"防备审视"到"深情守护"的转变
- 女主从"被迫求生"到"主动选择"的人性弧光
- 两人从"君臣"到"灵魂伴侣"的精神共鸣
- 共同理想：开创盛世，成就彼此

## 八、角色关系概览

### 核心三角

- **女主（苏晚/沈清欢）**：现代法医灵魂，聪慧独立，重情重义
- **帝王（萧衍）**：冷面深情，杀伐果断，深爱女主
- **白莲花贵妃（林若烟）**：表面柔弱，内心狠毒，终极反派之一

### 辅助角色

- 太后：幕后大boss，权力欲望极强
- 女二/闺蜜：与女主同甘共苦的嫔妃
- 忠犬侍卫：默默守护女主的暗卫
- 各色嫔妃：制造宫斗冲突的工具人

---

## 九、创作要点提醒

1. **穿越设定运用**：女主常以现代思维破解古代难题，但需适度"古代化"表达
2. **甜虐节奏**：每3集一个小甜→小虐循环，每10集一个大甜→大虐循环
3. **帝王人设**：前期冷峻多疑，中期宠溺霸道，后期深情专一
4. **打脸节奏**：反派嚣张必须够够的，打脸才够爽
5. **情感递进**：从"有趣"到"心动"到"深爱"，层层递进
