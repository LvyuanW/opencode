# 角色映射规则

目标：不照搬角色表层，而保留其叙事功能。

每个角色至少说明：

- 原角色
- 原角色功能
- 新角色
- 新身份外壳
- 仍保留的核心作用

## 常见功能

- 主角
- 对手
- 助攻
- 证据提供者
- 误会制造者
- 围观见证者
- 感情推动者
