# 分集撰写要求与自检清单

## 撰写流程

### 写前准备

每次撰写分集前，先确认以下信息：

1. **上集结尾**：上一集的最后一个场景和钩子是什么
2. **本集定位**：在全剧节奏中属于什么阶段（开局/发展/高潮/终局）
3. **本集核心**：这一集要完成什么（核心冲突/爽点/转折）
4. **下集衔接**：本集结尾要为下一集铺设什么悬念

### 撰写步骤

1. 先写本集的**节奏骨架**（3-5个场次的一句话概述）
2. 展开每个场次，按格式规范撰写
3. 检查字数是否≥800字
4. 检查开场是否在30秒内引爆
5. 检查结尾钩子是否够强
6. 通读一遍，确认节奏流畅

## 分集撰写要求

### 基础要求

- 每集字数≥800字
- 每集3-5个场次
- 严格遵循剧本格式（见 script-format.md）
- 每集标题简洁有力，暗示本集核心内容

### 情节设计要求

- **开场30秒引爆**：前3行内必须出现冲突或悬念
- **承接上集**：开头自然回应上集钩子
- **单集单核心**：每集围绕一个核心冲突或情绪点展开
- **至少2个爽点**：每集包含不少于2个爽点或反转
- **结尾留钩子**：最后10秒必须有让观众想看下一集的悬念

### 台词要求

- 直白、生动、有冲击力
- 单句不超过30字
- 每句台词必须推动剧情或揭示人物
- 爽点台词要有记忆点（适合截图传播）
- 口语化，避免书面语和文艺腔
- 不同角色的说话方式要有区分度

### 场景描写要求

- △ 描写简洁有力，每段不超过3行
- 注重画面感和动态描写
- 关键位置标注景别提示
- 环境描写服务于情绪——压抑的场景用阴暗色调，爽点场景用明亮/宏大
- 声音元素适当加入（♪ 音乐、环境音等）

### 视觉化与画面冲击

- 故事设计应包含强烈的视觉冲击场景
- 每个高潮情节配合一场强烈的戏剧化表演
- 台词、场景和动作描写应生动鲜明，强调画面感
- 示例：
  - "反派跪地求饶，主角冷笑不屑。"
  - "风雪中，主角一步步走向反派，眼神冰冷如刀。"
  - "百辆黑色轿车鱼贯而入，整条街被封锁。"

### 节奏要求

- 快节奏是第一原则——宁可牺牲部分逻辑也不能拖节奏
- 采用跳跃式叙事，不拘泥于场景过渡
- 不需要交代"他是怎么从A地到B地的"
- 大量使用跳切——上一秒在这里，下一秒在那里
- 每集的上一集尾声作为下一集开场延续

### 固定桥段与套路活用

熟练运用以下经典短剧桥段：

| 桥段 | 使用时机 | 效果 |
|------|---------|------|
| 被扇巴掌→反扇回去 | 羞辱场景 | 即时爽感 |
| 一个电话调来军队 | 身份碾压 | 震撼效果 |
| "你知道他是谁吗？" | 身份揭露 | 全场震惊 |
| 反派下跪 | 逆袭高潮 | 极致爽感 |
| 合同/证据当场出示 | 商战打脸 | 逻辑通畅的爽 |
| 刷卡不眨眼 | 财力碾压 | 物质爽感 |
| "三天之内，我要……" | 立flag | 期待感拉满 |
| 回忆闪回 | 真相揭露 | 恍然大悟 |

## 特殊集数撰写指南

### 第1集：爆炸开场

第1集决定了整部剧的命运。要求：
- 第一个场次的第一行就要抓人
- 30秒内建立主角困境和核心矛盾
- 本集结束时观众必须知道：主角是谁、他面临什么问题、为什么要继续看
- 最后留一个超强钩子——暗示主角不简单

参考开篇模板（见 opening-hooks.md）。

### 付费卡点集（第8-12集）

这是全剧最关键的1-2集。要求：
- 所有铺垫的线索在此汇聚
- 主角的真实身份/力量即将完全揭晓——但在最关键的一刻截断
- 反派的嚣张达到顶峰——观众极度渴望看到他被打脸
- 情绪推到最高点后戛然而止

### 至暗时刻集（第35-40集）

主角遭遇最大挫折的1-2集。要求：
- 让观众真正担心主角
- 之前积累的优势被打破
- 最信任的人背叛/最在乎的人受伤
- 但在绝望中埋下反击的种子

### 大结局集（最后2-3集）

终极收束。要求：
- 所有悬念必须收回
- 终极对决要有仪式感
- 感情线要有满意的交代
- 最后一个画面要有"余韵"——让观众回味

## 自检清单

每集写完后，对照以下清单逐项检查：

### 节奏检查 ✅

- [ ] 开场30秒内是否引爆冲突？
- [ ] 是否自然承接了上集钩子？
- [ ] 全集是否有拖沓的段落（超过30秒无冲突/信息）？
- [ ] 结尾钩子是否够强？

### 爽点检查 ✅

- [ ] 本集是否包含≥2个爽点或反转？
- [ ] 爽点强度是否与全剧进度匹配（越往后越强）？
- [ ] 爽点前是否有足够的铺垫和压抑？

### 台词检查 ✅

- [ ] 是否有超过30字的长台词需要拆分？
- [ ] 每句台词是否在推动剧情？
- [ ] 是否有"废话"台词（不推动剧情也不揭示人物）？
- [ ] 不同角色的说话风格是否有区分？

### 格式检查 ✅

- [ ] 场景头是否包含内/外、地点、日/夜？
- [ ] 出场人物是否列齐？
- [ ] △ 描写是否简洁（不超过3行）？
- [ ] 关键场景是否标注了景别提示？
- [ ] 字数是否≥800字？

### 连贯性检查 ✅

- [ ] 角色行为是否符合其设定？
- [ ] 是否与前面已写的集数有矛盾？
- [ ] 角色称呼、关系是否前后一致？
- [ ] 时间线是否通顺？

### 合规检查 ✅

- [ ] 是否有涉及暴力过度的内容？
- [ ] 价值观是否正向？
- [ ] 是否有敏感词或违规内容？
（详见 compliance-checklist.md）

## 批量撰写建议

当用户连续撰写多集时：

- 每5集做一次**小回顾**：确认角色弧线是否在推进
- 每10集做一次**节奏校准**：检查情绪曲线是否符合全剧规划
- 付费卡点前后3集要**特别精心**：这是全剧最关键的窗口
- 建议用户每次撰写1-3集，确认满意后再继续
